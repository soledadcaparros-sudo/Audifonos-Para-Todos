Sistema de Facturación y Control de Ingresos, Egresos y Ganancias

Audífonos para Todos

Descripción del proyecto

Este proyecto se desarrolla para la materia Organización Empresarial de la Tecnicatura Universitaria en Programación de la UTN.
El objetivo es diseñar un sistema informático sencillo que permita organizar y controlar los movimientos económicos del centro auditivo Audífonos para Todos.
El sistema permitirá registrar los ingresos según los diferentes medios de pago, controlar los egresos diarios y calcular automáticamente las ganancias al finalizar cada jornada.
También permitirá distribuir las ganancias en partes iguales entre los dos propietarios del centro auditivo.

Funcionalidades principales

Registro de ingresos diarios.

Identificación de los medios de pago.

Cálculo de impuestos y comisiones cuando corresponda.

Registro de egresos, como pagos a empleados y compra de insumos.

Cálculo de ganancias diarias.

Distribución de ganancias entre los dos propietarios.

Generación de un resumen económico diario.
